# スタッフインタビューの入力欄（microCMS）

`/staff-interview` のページは、microCMS の API **`staff-interview`**（オブジェクト形式・1 件だけ）から記事を読む。
以前の `staff-interviews`（リスト形式・スタッフ名と Q&A）は対談形式のころのもので、サイトは読んでいない。

## 反映のしかた

- 公開してから 1 時間以内にサイトに出る（ストーリーと同じ間隔）。
- **タイトルか本文が空のあいだは、コードに持つ「はじめの原稿」を出す**（API をまだ作っていない時も同じ）。
- 写真・リード・書いた人・スタッフの紹介は、空のままの項目だけ「はじめの原稿」のものを出す。
- microCMS が一時的に読めない時は、ページを作り直さず、前のページを出し続ける。

## API の作り方

1. microCMS の管理画面で「API を作成」→ API 名「スタッフインタビュー（記事）」、エンドポイント `staff-interview`、**オブジェクト形式**。
2. 「API スキーマを定義」で「ファイルインポートする場合はこちらから」を選び、[staff-interview.schema.json](./staff-interview.schema.json) を読み込む（繰り返しでない 6 項目が入る）。
3. API 設定 →「カスタムフィールド」で、下の 2 つを作る。
4. API 設定 →「API スキーマ」で、繰り返しの 2 項目（本文・スタッフの紹介）を足す。

フィールド ID はコードが読む名前なので、表のとおりに入れる。

### 項目

| 表示名 | フィールド ID | 種類 | 必須 | 入れるもの |
| --- | --- | --- | --- | --- |
| タイトル | `title` | テキストエリア | はい | 改行した位置で句を区切る |
| リード | `lead` | テキストエリア | | 本文のはじめに大きく出す文。改行で句を区切る |
| メインの写真 | `heroImage` | 画像 | | 一番上の写真（横長 3:2） |
| 文（書いた人の表記） | `byline` | テキスト | | タイトルの下の「文：」に続けて出る |
| 本文 | `sections` | 繰り返し（カスタムフィールド「本文のまとまり」） | はい | 見出しごとに 1 つ。記事のはじめのまとまりは見出しを空にする |
| 書いた人の名前 | `writerName` | テキスト | | 記事の最後の「この記事を書いた人」 |
| 書いた人の紹介 | `writerDescription` | テキストエリア | | |
| スタッフの紹介 | `staffProfiles` | 繰り返し（カスタムフィールド「スタッフ」） | | 記事の最後の「アイ企画のふたり」 |

### カスタムフィールド「本文のまとまり」（フィールド ID は自由。例: `interviewSection`）

| 表示名 | フィールド ID | 種類 | 入れるもの |
| --- | --- | --- | --- |
| 見出し | `heading` | テキスト | 目次にも出る |
| 本文 | `body` | テキストエリア | **空行で段落を区切る**。段落の中の改行はそのまま出る。段落の頭に `大地：` `恒成：` `ふたり：` と書くと、その人の発言として吹き出しで出る（例: `大地：「残せるものは残したいんです」`） |
| 写真 | `image` | 画像 | このまとまりの最後に出る（横長 3:2 に切り抜く） |

### カスタムフィールド「スタッフ」（フィールド ID は自由。例: `interviewStaff`）

| 表示名 | フィールド ID | 種類 | 入れるもの |
| --- | --- | --- | --- |
| 名前 | `name` | テキスト | 空の行は出ない |
| 顔写真 | `avatar` | 画像 | 丸く切り抜く。空なら、同じ名前の人のはじめの写真を出す |
| 紹介 | `description` | テキストエリア | |

## コードの場所

- 取得: `getStaffInterview()`（`src/lib/microcms/queries.ts`）
- 入力 → 表示用の形: `staffInterviewFromCms()`（`src/lib/staffInterview.ts`、テストは同じ場所の `.test.ts`）
- はじめの原稿: `src/app/staff-interview/page.tsx`
